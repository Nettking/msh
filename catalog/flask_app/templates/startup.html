Browser setup

Use this for normal first-time setup and for later changes. Settings are stored in data/server_setup/server_settings.json, so they persist across container rebuilds.

Use this when the server should record MTConnect data. Command-driven setup is still recommended for recorder-only machines.

This calls the local Ollama service and pulls the selected model. It may take several minutes on first run.

Command-driven alternative

Use this on servers where you want reproducible setup without browser prompts.

python setup_msh.py --mode full-server --ai-profile laptop-standard --start

Examples:

python setup_msh.py --mode web-workbench --ai-profile edge-small --start
python setup_msh.py --mode full-server --ai-profile workstation-strong --recorder-sources "IG500=http://192.168.200.251:5000/current" --start
python setup_msh.py --mode web-ui-only --no-ai --start
