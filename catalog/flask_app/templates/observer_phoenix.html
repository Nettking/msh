Where do I configure the vibration sensor?

The vibration sensor should be configured as part of the data source, not on Overview or Diagnostics.

Today

MSH can store Observer Phoenix connection settings here: base URL, username, password, TLS, and timeout.

Not implemented yet

There is not yet a dedicated UI for mapping a specific vibration sensor/channel to a machine, axis, or measurement type.

Next sensible feature

Add a source mapping section here for vibration channels, for example: machine, sensor name, signal/channel, unit, sampling rate, and enabled/disabled.
