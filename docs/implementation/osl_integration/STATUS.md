# Status of the preserved OSL integration plan

This directory is retained as a **source-pinned design and implementation-planning archive**. It was produced against the exact MSH, `systems-paper`, and `paper-repo` commits listed in `README.md` and does not describe implemented MSH behavior.

The material remains valuable because it specifies a complete candidate lifecycle that the shorter current plan does not capture in the same detail:

- low-friction source capture and immutable preservation;
- stable excerpts and candidate extraction with provenance;
- committed immutable OSL draft revisions, distinct from autosaved client drafts;
- deterministic profile validation without treating validation as truth or approval;
- authenticated human domain review of an exact unchanged revision;
- separate approval and publication commands;
- correction, rejection, deprecation, supersession, migration, and audit history;
- AI limited to suggestions and explanations, never review, approval, publication, or runtime authority.

The current bounded MSH entry point is `docs/planned-work/method-osl-msh-alignment.md`. Before implementation, agents must reconcile this archive with the then-current approved Notebook-to-OSL method contract and OSL language contract. Where the source repositories or current plan differ from this archive, the current approved contracts are authoritative.

Do not infer from the presence of these documents that save, completion, review, approval, publication, migration, or SysML/OSL conformance functionality has been implemented.
