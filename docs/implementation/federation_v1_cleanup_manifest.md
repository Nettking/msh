# Federation v1 cleanup manifest

Status: V1-B path-level cleanup manifest. This document records cleanup decisions and required evidence. It does **not** delete, move, rename, or modify any runtime path.

Baseline: `main` after the Federation v1 scope, repository audit, closeout plan, and post-v1 roadmap were added.

## Decision vocabulary

- **KEEP** — part of the supported v1 product or required operational evidence.
- **KEEP FOR NOW** — not proven removable; retain until a later focused review.
- **CONSOLIDATE** — preserve durable content in a canonical v1 document before removing the source file.
- **ARCHIVE** — preserve as historical architecture, security, test, or release evidence outside the normal user-documentation path.
- **DELETE CANDIDATE** — strong evidence supports removal, but deletion still requires a separate approved change and validation.
- **VERIFY BEFORE DELETE** — likely obsolete, but one or more dependency or migration questions remain.

## Required checks before every deletion batch

Before deleting any path listed here:

1. enumerate tracked files with `git ls-files` for the exact path or subtree;
2. search imports and textual references with `git grep`;
3. inspect dynamic script discovery, Flask blueprint registration, setup scripts, Docker Compose, launchers, tests, documentation links, and GitHub Actions;
4. verify AI indexing and cache consequences;
5. run the tests named for the row;
6. review the final diff for accidental runtime, configuration, or release-scope changes;
7. obtain separate repository-owner approval for the deletion batch.

Directory entries ending in `/**` mean every tracked file under that exact subtree. Hash-named generated cache files are intentionally represented by the subtree rather than copied individually into this document. The deletion implementation must attach the `git ls-files` output to its review evidence.
