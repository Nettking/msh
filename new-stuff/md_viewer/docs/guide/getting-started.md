# Getting Started

This page lives at `docs/guide/getting-started.md`. Notice that in the
sidebar, the **Guide** folder is expanded because you're currently inside it.

## Installation

```bash
pip install -r requirements.txt
python app.py
```

Then visit `http://127.0.0.1:5000/`.

## Adding your own docs

Just add markdown files under `docs/`. You can organize them into as many
folders and subfolders as you like — the navigation tree will follow.

- Standard markdown syntax is supported (headings, lists, links, images)
- Fenced code blocks get syntax highlighting
- Tables, blockquotes, and horizontal rules all work

> Tip: giving a file a leading `# Heading` makes that the page title and the
> sidebar link label falls back to a title-cased version of the filename.
