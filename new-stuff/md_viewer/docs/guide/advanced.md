# Advanced Usage

A few things worth knowing once you've got the basics down.

## Ordering files

Filenames are sorted alphabetically. If you want explicit ordering, prefix
files with numbers, e.g. `01-setup.md`, `02-configuration.md` — the numeric
prefix is stripped automatically when generating the display title.
